# Keepsake — Digital & Branding Agency

Адаптивний односторінковий лендінг дизайн-агенції Keepsake, виконаний у межах лабораторної роботи №7.

## Demo

Після ввімкнення GitHub Pages сайт буде доступний за адресою:
https://bohdan7563.github.io/landing-keepsake/

## Технології

- HTML5 із семантичною структурою.
- CSS3: Flexbox, адаптивні media queries та CSS custom properties.
- Google Fonts: Oswald, Open Sans, Dancing Script.
- Inline SVG для іконок.
- Невеликий JavaScript для доступного мобільного меню (кнопка з `aria-expanded` та `aria-controls`).

## Адаптивність

Базова версія орієнтована на мобільні екрани; додаткові стилі застосовуються на ширинах від 768px та 1280px. Контент має залишатися читабельним на вузьких і широких екранах.

## Запуск локально

Відкрийте `index.html` у сучасному браузері. Для локального сервера можна скористатися розширенням Live Server у Visual Studio Code.

## Примітка щодо зображень

На цьому етапі зображення підключені з вихідної папки лабораторної роботи в репозиторії `web-technologies`. Їх потрібно перенести до `images/` цього репозиторію, перш ніж видаляти вихідну папку.
